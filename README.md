# サークル向けお知らせ・掲示板システム

サークル運営をスムーズにするための、お知らせ配信および掲示板機能を提供するWebアプリケーションです。

##開発人数
- 1人

## 🚀 主な機能
- **お知らせ機能**: イベント情報や連絡事項の投稿・閲覧
- **掲示板機能**: メンバー同士の交流・コメント投稿
- **アルバム機能**: サークルの写真共有
- **データベース連携**: MySQL（MariaDB）によるデータ管理

## 🛠 使用技術
- **バックエンド**: PHP 8.x
- **データベース**: MySQL (MAMP環境)
- **フロントエンド**: HTML5, CSS3

## 📁 データベース構成
- データベース構築用のSQLファイル（`tennis.sql`）を直下に配置しています。
